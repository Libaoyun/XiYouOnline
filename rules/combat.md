# 汉风西游OL｜回合制战斗与数值法则规格 (Combat System)

> **版本**：v2.1（2026-10-03 单机战斗校订）
> **状态**：当前行为以 `js/core/battle.js` 与 `js/core/skills.js` 为准。
> **范围**：无底洞特色副本与 PVP 为后续蓝图；敌方部分专属招式仍采用简化攻击回退，不宣称全部 Boss 技能已完成。

## 1. 战斗框架与行动时序机制

汉风西游OL采用经典且深度的平视回合制战斗模式。每回合敌我双方按照速度属性决定行动先后，具有极高的策略博弈空间。

### 1.1 速度判定与先手压制法则
- **出手先后顺位**：战斗各单位依照【敏捷点数 → 基础速度 + 宝石速度加成 + 装备速度 + 极小随机微扰(±2%)】自高到低排定行动队列。
- **先手战略意义（先发制人）**：
  - **敏攻/敏法爆发**：高敏捷角色先手释放 **雷霆万钧**（高单体爆发）或 **舍生取义**（无视防御绝杀），能在敌方出手前完成点杀；
  - **先手神仙控制**：高敏神仙先手施放 **封印咒**（硬控无法行动）或 **乱魂咒**（自相残杀），直接打断对方核心输出轮次，甚至让对方一整回合无法行动；
  - **配速机制**：战术上要求封印角色速度高于敌方输出，己方解封/喂药角色速度精准卡在输出角色之前。

### 1.2 战斗指令全维度规格
在每个行动回合，玩家可在 30 秒倒计时内为自身及参战仙宠分别下达以下指令：

| 指令 | 目标类型 | 效果与结算逻辑 | 消耗与限制 |
| :--- | :--- | :--- | :--- |
| **物理攻击 (普攻)** | 敌方单体 | 根据攻击力与目标防御力结算伤害，触发暴击、反击、反震、致命一击判定。 | 无消耗 |
| **施放法术 (技能)** | 敌方单体/群体 / 己方 | 施放本门派或仙宠已掌握技能。受 5 级与 25000 熟练度法则严格增益。 | 消耗精力/法力值(MP) |
| **防御姿态 (防)** | 自身 | 进入招架状态，本回合受到的物理与法术伤害减免 50%，极大降低被致命暴击概率。 | 无消耗 |
| **使用药品 (药)** | 自身 / 己方队友 / 仙宠 | 使用背包中的药品，分为固定值恢复和百分比恢复（见道具章节）。中封印/乱魂者无法自用，但队友可对其喂药！ | 消耗对应药品 1 份 |
| **召唤仙宠 (宠)** | 战场空位 | 召唤备战席中的仙宠登场作战，或更换当前参战仙宠。登场当回合无法立即行动。 | 占用本回合行动指令 |
| **收服/招降 (捕)** | 敌方野生单位 | 对野生怪物进行捕捉收降：<br>① **凡宠**：普通招降指令直接概率收服；<br>② **散仙**：必须携带并消耗【收妖银壶】；<br>③ **金仙**：必须携带并消耗【收仙金壶】。 | 消耗对应银壶/金壶，首领与玩家不可捕捉 |
| **逃跑脱战 (逃)** | 全队 | 判定敏捷差值概率脱离战斗。剧情Boss战、无底洞副本战、武神斗及教派大战严禁逃跑。 | 逃跑失败本回合轮空受击 |

### 1.3 回合开始阶段：金仙【元神变身】与天赋生效时序
在每个行动回合正式启动、各单位排定速度队列之前，系统按严格的时序优先执行**金仙元神变身与天赋结算**：

```
     ┌────────────────── 回合初时序 (Round Start) ──────────────────┐
     │ 1. 状态持续回合递减 (中毒、封印、定身、变身剩余回合计算)      │
     │ 2. 金仙【元神变身】几率判定 (血量越低几率越高，满额3回合)   │
     │    ├─ 若触发：立绘法相化，加持【专属变身天赋】Buff            │
     │    └─ 成功变身时，该金仙永久获得 +1 天赋点                    │
     │ 3. 瞬时天赋生效 (猪八戒气血暴增、小白龙速度+100、牛魔物攻暴增)│
     │ 4. 敏捷动态重算，排定最终行动时序队列                        │
     └──────────────────────────────────────────────────────────────┘
```

1. **变身触发与逆境觉醒**：
   - 变身判定公式：$P_{\text{transform}} = P_{\text{base}} + 0.1 \times \left(1 - \frac{\text{curHp}}{\text{maxHp}}\right)$；
   - 气血越低变身几率越高，变身状态**固定维系 3 回合**；
   - 触发变身当回合立即获得 1 点变身天赋点（累计上限 5000）。
2. **变身天赋战斗介入法则**：
   - **速度重塑（黄风怪）**：普攻或技能命中敌方，概率（30%~70%）直接将其身法速度降为全场最低，立即将其在当前行动队列中移至最后顺位；群法命中则群体降速！
   - **伤害替死转移（白骨精）**：受到直接攻击时，5%~30% 伤害随机转移给场上一名单位（可能转移给敌方，亦可能转移给友方）；
   - **法力替血（沙僧）**：受到伤害时，15%~35% 伤害必中从法力值扣除，法力不枯竭则气血不倒；
   - **气血与狂暴（八戒/牛魔）**：八戒变身瞬间暴增海量气血（+2000 HP 及 +35% 最大HP）；牛魔王变身增血同时大幅提升物理攻击力（+50% 物攻，仅普攻生效）。

### 1.4 反击与反震结算（2026-10-04 实装）
挂链与变身天赋提供的反击／反震此前只写进面板、战斗从不读取，本轮已接入受击链路：
- **反震（reflect）**：受击方按 `reflectRatio`（取挂链 `counterShockRate` 与黑熊精化劲天赋的较大值）把**本次实际扣除的气血**按比例反弹给攻击者，并立即重算战场生命；
- **反击（counter）**：受击方按 `counterAttackRate` 概率发动一次还击，造成本次实际扣除气血 35% 的物理伤害；
- 两者均在**防御天赋结算之后**计算，即法力抵扣、逆御免伤、画皮移伤扣掉的才是反震与反击的基数；
- **致命一击的真伤不触发反震**（无视防御与抗性，不属于可反弹的伤害）。

### 1.5 变身天赋结算顺序（受击方）
```
法力抵扣(流沙护体) → 逆御免伤(羊脂封魄) → 画皮移伤(白骨精)
        → 扣除气血 → 反震 → 反击
```
命中方的吸血／吸蓝／断速／破障在**伤害确认后**结算，断速会立即重排行动时序。

### 1.6 战斗指令目标点选时序与聚焦预览确认规范（2026-10-05 闭环）
- **先选指令，后选目标**：玩家发起出招指令（普通攻击、单体技能、药品使用、法宝收服等）后，若可选目标存活数 $\ge 2$，系统自动展开目标选择面板，严禁直接自动出招；
- **单目标聚焦预览，杜绝全员血蓝透视**：
  - 严禁一次性展示所有存活目标的血量与法力；
  - 目标面板上层提供纯名称序号目标切换标签行（如 `[1. 偷粮硕鼠·甲] [2. 偷粮硕鼠·乙]`）；
  - 中层**仅且仅展示当前聚焦选中的那 1 个目标**的状态卡片（当前与最大生命值、当前与最大法力值）；
- **自由切换与显式确认出招**：
  - 玩家可通过点击切换标签、按键盘数字键 1~9 或使用左右箭头/Tab键在各存活目标间自由切换预览；
  - 切换目标期间仅更新预览卡片，绝对不提前执行出招；
  - 直到玩家明确确认（点击【⚔️ 确认出招】按钮或按 `Enter`/`Space` 空格键），指令方正式下达并锁定目标；
  - 玩家亦可随时点击【◀ 返回重新选择指令】或按 `Esc`/`Backspace` 取消目标选择并退回指令矩阵。

## 2. 核心数值模型与伤害公式

### 2.1 物理基础伤害与减免
$$\text{PhysicalDamage} = \max\left(1, (\text{Atk} - \text{Def}) \times \text{SkillRate} \times \text{MasteryMult}\right) \times \text{CritMult} \times \text{Fluct}$$

- **力量与攻击力**：每点力量提供物理攻击力加成；
- **体质与防御力**：每点体质提升最大气血(HP)与基础防御力(Def)；
- **暴击与致命**：
  - **暴击 (钻石宝石提供)**：触发时造成 150% 物理暴击伤害；
  - **致命一击 (红宝石提供)**：无视目标防御直接扣除当前最大气血比例（常规怪物 20%，剧情Boss 8%）；
  - **反击 (绿宝石提供)**：受到物理近战伤害时，概率反戈一击；
  - **反震 (琥珀宝石提供)**：受到物理伤害时，将一定比例伤害反射给攻击者自身。

### 2.2 舍生取义绝杀法则（硬核保真）
舍生取义为金刚职业的核心绝杀技，其威能超越凡俗，**完全无视目标物理防御力**，但自身需承担气血反噬：
- **无视防御机制**：伤害完全由自身等级、攻击、技能等级与熟练度决定，哪怕面对玄铁玄龟亦能打出真伤；
- **气血施展门槛限制（核心铁律）**：
  - **当前气血低于 10% 无法使用**：自身生命值低于 10%（`hp < maxHp * 0.1`）时无法施展该技能；
  - **1 点残血锁死与续发禁用**：若当前气血刚好为 10% 或者不够单次自损扣血时，**自身气血强制保持在 1 点濒死状态**；下次因当前血量必定低于 10%，绝对无法连续使用，除非使用药品或治疗恢复到 10% 以上！
- **反噬模型与熟练度梯度表**：
  - **Lv.1 (0~5000 熟练度)**：0 熟练度初始伤害 **500**，反噬 0，耗蓝 220；10 熟练度以内反噬为 0；超过 10 熟练度后伤害为 501 且自身损血 1 点；1000 熟练度为 650 伤害、40 点自损、250 蓝耗；
  - **Lv.2 (1000 提前突破门槛)**：基础伤害 **1,600**，自身自损 **400** 点气血，耗蓝 350；
  - **Lv.3 (6000 提前突破门槛)**：基础伤害 **3,500**，自身自损 **1,500** 点气血，耗蓝 450；
  - **Lv.4 (11000 提前突破门槛)**：基础伤害 **7,000**，自身自损 **3,500** 点气血，耗蓝 560；
  - **Lv.5 (25000 巅峰满熟练度)**：最高伤害达 **约 16,000** 点破甲绝杀！自身单次承受 **8,000** 点反噬自损，耗蓝 850。

### 2.3 妖魔五行法术伤害与必中法则
- **雷霆万钧 (男妖 - 极强单体雷系)**：
  - 召唤九天神雷轰击单个目标，法伤基础系数极高；Lv.1 0熟练度伤害即达 **420** 点，法力消耗高达 300 点；
  - **Lv.5 满 25000 熟练度**：伤害高达惊人的 **12,608** 点！为全服最强法系单体核爆；
  - 受目标【抗落雷】属性减免（由蓝宝石、玛瑙提供）。
- **飞砂走石 (风系群体) & 三昧真火 (火系群体)**：
  - 妖魔群法具有 **必中特性 (Cannot Miss)**，无视目标的物理闪避率；
  - 分别受到目标【抗风沙】（绿宝石、猫眼石）与【抗妖火】（红宝石、水晶）削弱抵扣。
- **万毒攻心 (女妖 - 75% 阶梯递减剧毒)**：
  - **官方首创递减衰减模型**：第 1 回合造成满额毒伤；第 2、3、4 回合持续损血，伤害精确为上一回合的 **75%**；
  - **多重叠加有效**：每回合对同一目标重复使用，中毒层数与持续衰减伤害完全叠加！

### 2.4 佛门玄击双轨百分比削损法术与【抗玄击】法则
佛门金刚专属法门统称为【玄击】，其杀伤机制跳出传统攻防对抗，**主打百分比削损，基数辅助**：
- **玄击双轨计算公式**：
  $$\text{Damage} = \left(\text{BaseDmg} + \text{Target}.\text{curHp} \times \text{HpRatio}\right) \times (1 - \text{ResXuanji})$$
  $$\text{MpDrain} = \left(\text{Target}.\text{curMp} \times \text{MpRatio}\right) \times (1 - \text{ResXuanji})$$
- **佛光普照 (男金刚单体)**：
  - Lv.1 0熟练度基数仅为 **150** 点，满级满熟练度基数达到 **1,500** 点；
  - 生命削扣 20%~38%，法力削扣 10%~20%（实战如某阶段熟练度达到 **600 伤害基数 + 30% 敌方当前生命 + 15% 敌方当前法力**）；
- **如来神掌 (女金刚群体)**：
  - Lv.1 0熟练度基数仅为 **100** 点，满级满熟练度基数达到 **1,000 / 每位**；
  - 效果比佛光单体低（12%~24% 当前生命，6%~13% 当前法力），但随技能升级可覆盖轰击全队多达 4 人；
- **【抗玄击】全服唯一法则**：
  - 针对佛光普照与如来神掌的抗性统一命名为 **【抗玄击】**；
  - **全服没有任何宝物、装备或宝石可增加抗玄击**！装备抗性对玄击完全无效；
  - 全服唯一的抗玄击来源为 **金刚职业天生自带 5% 抗玄击**。

## 4. 异常状态、控制与破封解除机制

在汉风西游OL战斗中，状态掌控往往凌驾于纯输出之上。四大核心控制/增益状态判定逻辑如下：

### 4.1 封印 (神仙 - 封印咒)
- **状态效果**：受控目标全身被法印禁锢，**完全无法行动**（不可普攻、不可施法、不可自用药品、不可召唤或逃跑）；
- **救援与破除**：虽然中计者自身无法用药，但 **己方队友可以正常对其喂药补给**；敌方依然可以对其进行正常伤害打击；
- **命中率与成长**：初始命中率为 **62%**，满级满熟练度高达 **95%**；受目标【抗封锁】（蓝宝石、珍珠）抵扣。

### 4.2 乱魂 (神仙 - 乱魂咒)
- **状态效果**：陷入心魔狂乱，**随机自动攻击场上任意单位**（包括敌方与己方队友！）；中计后无法控制行动，自身无法使用药品；

- **命中率与成长**：初始命中率约 **45%**，满级满熟练度约 **85%**。

### 4.3 定身 (神仙 - 定身咒)
- **状态效果**：数回合内无法使用物理攻击和主动攻击技能；
- **允许行为**：中计者 **依然可以使用物品指令、自用药品、以及召唤备用仙宠**；
- **受击苏醒机制 (核心特色)**：如果对处于定身状态的目标进行任何伤害攻击，**目标立刻苏醒解除定身状态**！
- **命中率与成长**：每个目标初始命中率为 **33%**，满级满熟练度单体高达 **75%**；受目标【抗围困】（绿宝石、琥珀）抵扣。

## 5. 特色战役与副本战斗机制

### 5.1 野外战斗与仙宠招降
- **凡宠捕获**：野外普通战斗中，使用【招降】指令对野生精怪（如野兔、青蛇、狐狸精）进行收服，成功率与目标剩余血量挂钩；
- **散仙收服**：遇战嫦娥、巨灵神等散仙时，背包必须备有【收妖银壶】方可激活收服指令；
- **金仙收服**：遇战猪八戒、沙和尚、白骨精等金仙时，背包必须备有【收仙金壶】方可成功点化收入麾下。

### 5.2 无底洞战役（后续副本规划，当前未实现）
汉风西游经典高阶副本“无底洞”包含精密的走位与打法机制：
1. **红桃抢夺战**：第一阶段场景内与猴群抢夺仙桃，精准击破“红色仙桃”，触发隐藏守关 Boss；
2. **Boss 10% 狂暴灭队防范**：Boss 气血被打至 10% 斩杀线时，会释放全屏大招“暴怒灭队技”。此时辅助门派（如五庄）必须立刻走开拉开距离躲过暴怒状态，避开灭顶之灾后返回救拉队友；
3. **连续击杀两次**：该 Boss 拥有涅槃复生特性，必须连续击杀两次方可彻底破除其不灭法身；
4. **百折林穿梭与婢女刺杀**：百折林迷宫由特定敏捷速度成员跑位至核心 Boss 婢女身侧，定点集火斩杀婢女，全队方可通过；
5. **地涌夫人牌位战**：最终决战全力倾泻火力摧毁牌位本体，取得通关重宝。

### 5.3 PVP 竞技盛典（后续联机规划，当前未实现）
- **武神斗大赛**：每周三、周五 21:00-22:00 举行全服 15 级以上天梯排位决战。严格采用动态防作弊机制，胜者问鼎全服 1~3 名，赢取 2000 金砖与 5 级宝石；
- **教派大战**：每周由各大教派精英组队对抗，分淘汰赛与决赛两阶段，角逐天下第一教派神座。战斗不损耗经验与装备耐久，全面展现门派配合与宝石抗性博弈。

## 6. 当前单机执行与演出约定（2026-10-03）

- 控制和群伤先以选中目标为首目标，再按存活顺序选取其他目标。毒术／控制命中率扣除对应目标抗性，失败也回传结果。
- 封印阻止操作；定身阻止普攻和施法、允许用药，受到正伤害后解除；乱魂将本次行动替换为对随机其他存活单位的普攻。
- 状态每回合末结算。一般新状态应用当轮不减时长，后续回合递减；防御当轮末消失。毒术初次伤害立即结算，之后每轮伤害为上一轮的75%向下取整，总时长包含初击，各层独立。
- 护体的物防增幅与常规法术减伤取有效状态中的最大值，不重复叠乘；舍生与佛光／神掌玄击不受护体法术减伤。
- 敌方雷霆、真火、风沙使用技能公式并扣MP；封印、定身、乱魂与护体执行实际效果。敌方这些招式暂按Lv.1／熟练度0，其他专属技能仍需逐一接入。法力不足回退普攻，选中阵亡单位时重新选存活目标。
- 法力不足回退时不保留技能名或技能伤害加成；元素致死伤害仍判定已有神佑复生。战中换宠同步新宠的等级、战力、抗性与模型。
- 成功逃跑立即结束本轮，不继续敌方行动；同伴旧字符串技能在战斗入口转换，不改写原始存档数组。
- 结算回调携带 `skillId`、`skillName` 与群体 `hits`／实际受益 `targetIds`。群体共用一次施法及背景，局部特效与逐目标飘字同时展示。
- UI暂存显示气血、法力、状态与回合站位，命中时同步；阵亡单位先承受命中特效再退场。闪避只有位移和闪避提示，无命中刀光、音效与震屏。
- 二倍速覆盖蓄力、突进、命中、归位和法术时长。普通兵器招式用刀光；舍生独享宽光束、细射线、收束与命中后爆炸阶段。
- 战斗清退：敌方全部阵亡为胜利，玩家气血归零为战败。回合演出锁解除后由 `endBattle(status)` 停止倒计时与动画循环、隐藏战斗层、解除暂停，并且仅执行一次对应回调。战败恢复气血；逃跑不发胜利奖励。界面巡检不能打断致死演出，旧回合/自动出招不能控制新战斗。战后取消移动与按键并短暂抑制贴身重遇敌。不提供直接强制获胜按钮。
